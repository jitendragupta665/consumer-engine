# Consumer Engine

A research-to-product platform for discovering real consumer problems, validating demand, building software, and acquiring customers.

## Mission
Evidence-first B2C opportunity discovery across education, health, finance, commerce, productivity and other sectors.

## Workflow
Collect permitted public data → normalize evidence → classify sector and problem → deduplicate → validate prevalence and willingness to pay → rank opportunities → build MVP → measure activation, retention, revenue and profitability.

## Status
Repository initialized. Data collectors, scoring engine, API, dashboard and automated tests are planned, **not yet deployed**. Do not confuse online complaints with paying customers.

## Safety
Respect site terms, API rate limits and privacy. Do not commit API keys or personal information.
